# Contributing

## Branches

- One branch per issue, created from an up-to-date `main`.
- Name: `<type>/<task>-<topic>`, for example `docs/t03-service` or `chore/t05-codeowners`.
- Types: `feat`, `fix`, `docs`, `chore`.

## Commits

- Imperative mood, subject up to 72 characters: `Add CODEOWNERS`, not `added codeowners`.
- One logical change per commit.

## Pull requests

- Nothing goes straight to `main`; every change is a pull request.
- The description says what changes and ends with `Closes #<issue>`.
- Check the diff in Files changed before merging; then **Squash and merge** and delete the branch.
- Conflicts are resolved locally in the terminal; `main` is never force-pushed.
